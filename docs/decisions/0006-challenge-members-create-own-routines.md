# ADR 0006: 챌린지 참가자는 자신의 루틴을 생성한다

- 상태: 승인됨
- 날짜: 2026-07-14

## 결정

- 1:1 챌린지 생성자는 초대와 동시에 자신의 계획·루틴을 생성한다.
- 초대 수락자는 자신의 사용자 ID로 별도 계획·루틴을 생성한다. 따라서 각 참가자의 시간대와 루틴 데이 설정은 서로 영향을 주지 않는다.
- 두 루틴 생성 모두 기존 활성 루틴 제한 trigger를 사용한다. 수락자가 제한에 도달한 경우 수락 전체가 실패하고 초대 상태는 유지된다.

## 결과

- 챌린지 멤버는 자신의 루틴 항목을 소유하며, 후속 체크인과 통계는 기존 사용자별 도메인 규칙을 재사용한다.
- 초대 수락이 무료 제한을 우회하지 않는다.
