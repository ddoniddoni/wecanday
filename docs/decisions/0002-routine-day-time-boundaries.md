# ADR 0002: 루틴 데이의 현지 시간 경계

- 상태: 승인됨
- 날짜: 2026-07-12

## 결정

- 루틴 데이는 IANA 시간대와 `dayStartMinute`(0~1439)를 기준으로 계산한다.
- 각 구간의 시작과 끝은 해당 지역의 같은 현지 시각으로 만든 뒤 UTC ISO 문자열로 저장·전달한다.
- DST 전환일에도 현지 시작 시각을 우선한다. 따라서 구간 길이는 23시간 또는 25시간일 수 있다.
- 존재하지 않는 현지 시각(봄 DST 전환의 02:30 등)은 `TZDateMini`의 호환 동작에 따라 전환 이후의 첫 유효 현지 시각으로 이동한다. 겹치는 현지 시각(가을 전환)은 첫 번째 발생 시각을 선택한다.
- 하루 시작 시각 설정 변경은 현재 루틴 구간의 `endsAt` 이후에만 적용한다. 과거 체크인의 `routine_day`는 다시 계산하지 않는다.

## 결과

- 화면과 이후 서버 로직은 `getRoutineDayWindow`만 사용해 루틴 데이 키와 UTC 경계를 얻는다.
- 기기 기본 시간대와 UTC 날짜를 사용자 루틴 데이로 직접 사용하지 않는다.
