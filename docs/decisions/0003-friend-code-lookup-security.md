# ADR 0003: 친구 코드 검색의 최소 공개와 속도 제한

- 상태: 승인됨
- 날짜: 2026-07-14

## 배경

친구 찾기는 사용자가 공유한 12자리 Base62 코드를 정확히 입력했을 때만 가능해야 한다. `profiles` 전체 목록을 클라이언트에 열면 코드 수집과 개인정보 노출 위험이 생긴다.

## 결정

- `public.profiles`는 본인 행만 직접 조회하는 RLS 정책을 유지한다.
- `lookup_profile_by_public_code` RPC는 인증된 사용자만 호출할 수 있는 `SECURITY DEFINER` 함수로 두고, 고정된 빈 `search_path`에서 최소 필드(`id`, `display_name`, `avatar_seed`)만 반환한다.
- 자기 자신과 어느 방향으로든 차단 관계가 있는 대상은 결과에서 제외한다. 차단 관계 데이터는 RLS가 켜진 `user_blocks`에 두며, 후속 차단 기능 전까지 클라이언트 직접 권한을 부여하지 않는다.
- 유효한 코드 조회는 사용자별로 달력 분당 10회까지 허용한다. 카운터는 private 스키마에 두고 RPC 안에서 원자적으로 갱신한다.
- IP 기반 이상 탐지는 신뢰할 수 있는 원격 IP를 얻을 수 있는 Edge Function 또는 API 게이트웨이를 도입할 때 추가한다. 현재 RPC에는 검증 가능한 IP가 전달되지 않으므로 임의 헤더 값을 저장하지 않는다.

## 결과

- 검색 결과는 존재 여부를 자동완성이나 부분 검색으로 수집할 수 없고, 이메일·국가·루틴·구독 상태를 포함하지 않는다.
- `SECURITY DEFINER` RPC가 `authenticated`에 실행 허용되어 있다는 Advisor 경고는 이 제한된 공개 경로에 대해 의도된 상태다. 익명 역할과 직접 테이블 조회 권한은 없다.
- 향후 T-404는 `user_blocks` 작성·해제 RPC와 차단 UI를 추가하고, IP 기반 탐지 경로가 도입되면 이 속도 제한 정책을 보강한다.
